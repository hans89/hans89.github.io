Internship at Google

Created on 2018-12-12 | Categories: activities | Tags: #google #internship #V8 #JavaScript

From August to October 2018 I had a three-month internship at Google Munich. I was working in the V8 team, specifically with Georg Neis and Sigurds Schneider. My hosts were very nice to work with, and I had the opportunity to work on optimizing JavaScript code using V8's internal language CodeStubAssembler (CSA). CSA is a C++-based assembly-like goto language that generates assembly code for every architecture that Chrome supports.

A description on my internship work can be found on the V8's blog post.

I also gave a talk about RustBelt during my internship.
